## 📌 Estado del Proyecto
**🚧 En Desarrollo Inicial** - Diseño de arquitectura de base de datos

Este repositorio contiene el diseño y modelado de una base de datos relacional para un sistema de gestión veterinaria. Actualmente se encuentra en fase de planificación y diseño del esquema.

## 🎯 Objetivo
Desarrollar un sistema integral para la gestión de clínicas veterinarias que permita:
- Registro de clientes y mascotas
- Agendamiento de citas médicas
- Historial clínico digital
- Facturación y control de servicios
- Gestión de veterinarios y especialidades

## 🏗️ Arquitectura Planeada
El sistema estará compuesto por las siguientes entidades principales:
- **Cliente**: Propietarios de mascotas
- **Mascota**: Pacientes veterinarios
- **Veterinario**: Staff médico
- **Cita**: Agendamiento de consultas
- **Historial Clínico**: Registros médicos
- **Servicio**: Catálogo de prestaciones
- **Factura**: Transacciones económicas

## 🛠️ Stack Tecnológico (Planificado)
- **Motor de Base de Datos**: MySQL
- **Entorno de Desarrollo**: XAMPP
